# Animal Taxonomy CBT (생물분류기사 동물 실기 대비 프로그램)
생물분류기사 동물 실기 시험 대비를 위해 구축된 Flask 기반의 키보드 최적화 CBT 웹 애플리케이션입니다.


## 🚀 주요 기능
1. **실전 모의고사**: 25문제 또는 50문제 세트를 구성하여 실전과 같은 모의고사를 진행합니다. 각 문항마다 점수가 매겨지며, 총점 100점 기준으로 최종 결과가 출력됩니다.

2. **핵심 6개 평가 항목**: `문`, `강`, `목`, `과`, `종명`, `멸종위기종 여부`를 2줄 레이아웃으로 한눈에 입력할 수 있습니다.

3. **키보드 최적화 단축키**:
   - `Space`: 멸종위기종(-, Ⅱ, Ⅰ) 라디오 버튼 직관적 선택
   - `Tab` / 방향키: 매끄러운 입력 이동 및 사진 스크롤
   - `Ctrl + 휠`: 고화질 사진 세밀 확대

4. **동물 종 검색 도감**: 목, 과, 종명 등으로 빠르게 검색하여 형태적 특징과 사진을 대조 학습할 수 있습니다.

5. **맞춤 모의고사**: 학습자가 원하는 동물 종만 커스텀 체크하여 집중 타격 모의고사를 지원합니다.
